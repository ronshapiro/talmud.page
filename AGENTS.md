# Repository Conventions

- In this codebase and Sefaria's data model, `ref` is the canonical domain term for a passage identifier. Examples are: `"Bava Kamma 2a"`, `"Genesis 1:1"`, `"Berakhot 2a:1"`).
- Retain `ref` and `refs` in variable/function names (e.g., `ref`, `refs`, `mergeRefs`, `refSorter`, `refSuffixIndex`).
